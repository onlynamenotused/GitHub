Log code mapping

Mimaki doesn't publish its log event codes. These rules were worked out from a known engineer visit (TxF150 FD39B916, 27/02/2025): 016/001 appears as a start→end pair (value 6→262) when the station/cap maintenance runs, and 004/xxx and 005/xxx appeared once each mid-visit. Confirm or correct them against more of your visit logs, then set the status to confirmed. The hourly task and this page both read the saved mapping.

How to run a review

Reviews are run by hand. There is no email intake or automatic reply.

  1. In a Claude chat: attach the machine's log and parameter CSVs (or point Claude at a folder on your PC) and ask for a Mimaki log review. Claude reads the serial from the parameter file, compares the machine with its previous reviews and the fleet, files the PDF in Vendors › Log Review › <SERIAL> and saves the review here.
  2. Or in this page: open Analyse files, drop the CSV/XLSX files in, check the result and click Save to database. Use the chat route when you need the PDF report.
  3. To compare before and after, upload both parameter files together, in any order and with any names. They are put in time order from the machine's own counters (power-on time, power-off day counter, wipes, print length, cleanings) and the engineer-only changes between them are listed. Changes since the machine's previous review are listed too.
  4. Each log file only holds about the last 2–5 weeks: the printer keeps a fixed 65,536 entries and overwrites the oldest. Export logs every 2 weeks for a continuous record; gaps between logs show as no log data, and the parameter data only section uses the parameter files' dates and running totals to cover them.
  5. Export as PDF (Machine view and Analyse files) prints the review on screen; choose Save as PDF in the print dialog.
  6. Reset (top right) takes you back to the fleet dashboard and clears filters, uploaded files and any review you haven't saved. Saved reviews stay in the database.
  7. In Analyse files the From/To dates show the period the uploaded logs cover; narrow them to review only part of it.
  8. When the earliest parameter file is factory-fresh (power-on counter, wipes and print length near zero) the visit is treated as a new install: the before and after files are compared with other installs of the same model, and settings that every other install changed but this one didn't are listed as possibly missed.
